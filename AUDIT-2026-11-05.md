## The battery (v0.1.4, 2026-11-05/06, full 20-run re-measurement)

Protocol: identical to the published measurement — fresh session per run, verbatim prompt (`/one-shot ` prefix in the skill arm; ambient skill catalog present in both arms), one prompt, no follow-ups during the build; MANUAL criteria judged from each run's recorded verification evidence with the fixed scorer doing static criteria; every run sentinel-gated via the new `complete` subcommand.

Deviations, disclosed: runs executed sequentially (account concurrency limit — two background launches and one quota interruption failed and were retried; one run began from the partial draft its quota-killed attempt left, noted in that record); the ambient catalog now also contains the dev-studio team playbooks (both arms equally — internal comparison valid, comparison against the October battery confounded); the harness cannot deliver trusted OS key/click events, so input-path evidence is synthetic-event-level in several runs (disclosed per record); two RESULT notes were corrected post-hoc (skill/03/run1's c2 provenance; skill/01/run2's c7 journey) — the corrections are in the records, not hidden.
