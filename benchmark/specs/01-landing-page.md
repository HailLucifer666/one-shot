# Spec 01: Landing page

Build a single-page landing page for FocusDesk, a desk-booking tool for small offices. Static site, no backend.

## Requirements
- Sections: hero, three benefits, how it works (3 steps), FAQ (4 questions), final call to action, footer.
- Primary button text: Book a free demo. It links to #demo, a form section with name and work email.
- Responsive from 360 to 1440 px. Light theme only.

## Acceptance criteria (yes or no)
1. Page loads from a local file or dev server with no console errors.
2. Exactly one h1 exists and it states what the product does.
3. All six required sections are present, in order.
4. Primary button text matches and the #demo form has labeled name and email inputs.
5. No sideways scrolling at 360, 768 and 1280 px.
6. Body text contrast is at least 4.5:1.
7. No lorem ipsum, no invented statistics or testimonials.
8. Title, meta description and favicon are set.
9. Every image has alt text, or there are no images.
10. Keyboard focus is visible on all links, buttons and inputs.
